左侧连接列表 · 10 套 Cult UI 风格方案

每一套都是值区头部（票根 + 水印）的邻居：配色沿用当前主题令牌，圆角、描边粗细、悬停节奏与值区保持一致，换上去不会像"两个软件拼在一起"。 每个方案给出亮 / 暗两种主题，同一份 DOM 结构，差异全在 CSS —— 选定后可直接落地，无需改组件结构。

数据取自真实形态：已连接 / 连接中 / 连接失败 三种状态， 置顶 标记，SSH 跳板与 db0 库序号徽标，长名字截断，失败行带错误信息。

结构改动小，风险低 需要少量新 DOM 表达优先，接受结构重排
01
票据存根 Ticket Stub
直接复用值区头部的票根语言：左侧 26px 存根竖排首字母，右缘用 mask 咬出半圆撕口。 整页只有这一处用撕口，它就成了"连接 = 一张通行凭证"的专属记号，与值区形成上下呼应。 代价是需要给每行补一个 .stub 子元素。
需新 DOM
02
玻璃叠层 Frosted Stack
侧栏底部铺两团低饱和光斑，行是半透明玻璃片，靠 backdrop-filter 吃进背后的颜色。 激活项只提高不透明度与描边亮度，不加色块 —— 层次靠"厚度"而不是"颜色"表达。结构改动为零。
仅 CSS
03
霓虹描边 Neon Rim
激活项用 conic-gradient + mask-composite 做 1px 渐变描边，状态条同步换成同色渐变并发光。 静态时克制，选中时才"通电"。注意：渐变描边在 125%/150% 缩放下需验证 1px 是否被取整成 2px。
仅 CSS
04
终端信纸 Term Paper
整栏切等宽字体，行底铺 22px 节拍的横格线，标题前加 #、名字前加 $。 最"Redis CLI"的一套，代价是中文名字在等宽字体下会略窄，需要单独指定回退字体。
仅 CSS
05
竖脊水印 Spine × Ghost
把值区头部的另一半语言搬到行上：22px 竖脊放首字母，行右侧压一个大字水印（attr(data-letter)，不占 DOM）。 与 01 是同一家族但更轻 —— 没有撕口，只剩"脊 + 虚压痕 + 水印"。
需新 DOM
06
磁贴网格 Tile Grid
两列小卡，连接数多时一屏能装下双倍；服务地址单独占一行，状态条变成卡片顶部的一小段短线。 主要风险：连接名较长时两列会挤，需要收紧截断长度；拖拽排序在两列布局下的落点语义也要重新定义。
结构重排
07
胶囊标签 Pill Rail
单行紧凑：状态点直接替代左侧状态条，地址与徽标收进 tooltip。最省纵向空间，一屏能放 12+ 个连接。 代价是地址不再常驻可见 —— 而"连的是哪个库"恰恰最常需要确认，建议至少在 hover 时浮出。
需新 DOM
08
文件树 File Tree
引入一条竖向主干与横向支线，把连接读成树的一层 —— 为将来「分组 / 环境折叠」留好视觉接口。 现在只有一层时略显架空，但它是最容易"长大"的一套。
仅 CSS
09
数据条 Signal Bars
把延迟从数字升级成右侧竖条：一眼看出哪个实例慢，不用逐个读 121ms。 用 data-lat 驱动 --fill，无需 JS 计算。
需新 DOM
10
液态玻璃 Liquid Glass
最接近主页 candy 按钮那套质感：双色光斑打底、玻璃片有内高光与外投影、hover 时抬起 1px 并有一道高光扫过。 表达最强，但透明叠层在低端机或远程桌面下 blur 会掉帧，且是 10 套里最挑主题配色的。
表达优先

怎么选
想和值区票根成套 → 01 或 05（同一家族，辨识度最高）。
只想换气质、不动结构 → 02、03、04、08（纯 CSS，一天内可落地）。
连接很多、要一屏扫完 → 06、07（但都要接受信息密度上的取舍）。
要最能体现 Cult UI 质感 → 10（性能与主题适配成本最高）。
